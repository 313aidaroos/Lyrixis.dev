# Lyrixis brand kit

One folder, served at `/brand/`. PNG and ICO only. Do not add another logo file anywhere else in the repo.

Colors are the ones in `brand.json`. The site theme uses the same hex values: `--violet`, `--cyan`, `--bg`, and `--ink` in `app/globals.css`.

| Token | Hex | Where it shows up |
|---|---|---|
| primary | `#8b5cf6` | Violet accent |
| accent | `#22d3ee` | Cyan accent |
| background | `#07061a` | Page background, icon tiles, link preview |
| text | `#f4f2ff` | Main text |

## Which file to use

- `logo-full.png` — mark and the Lyrixis name together, transparent. Headers, footers, and anywhere the lockup sits on a light or photographic background.
- `logo-full-white.png` — the same lockup as flat white, for a dark background where the chrome letters would disappear.
- `mark.png` — the note-shaped L alone, transparent. Favicon source, hero symbol, avatars.
- `mark-white.png` — the same mark as flat white, for a dark background.
- `favicon.ico` — browser tab. Contains 16×16 and 32×32.
- `favicon-32.png` — 32×32 PNG tab icon.
- `apple-touch-icon.png` — 180×180, mark centered on the background color.
- `icon-192.png` and `icon-512.png` — home-screen icons, mark centered on the background color.
- `og-image.png` — 1200×630 link preview. The full logo is centered on the background color.

The white files are flat white recolors of the cutout. They are not separate drawings.

`banner.png`, `facebook-cover.png`, and `facebook-profile.png` are not in this folder yet.
